## Important Notice

The data found in this folder is from SARS-CoV-2 Data Repository for the Ontario Wastewater Surveillance Consortium (OWSC), which [can be found here](https://github.com/OntarioWastewaterSurveillanceConsortium/sars-cov-2-data/tree/main), and the COVID-19 wastewater surveillance data from Quebec City generated by ModelEAU and MiCEL, which [can be found at this link](https://zenodo.org/records/5597158). Some additional data is prepared from the [Delatolla Research Group's](https://www.delatolla-research-group.ca) work on [613covid](https://613covid.ca/wastewater/), which is made available at the [PHESD data repository](https://github.com/Delatolla-lab/PHESD).

Both these data sources record data in version 1.1 of the PHES-ODM. While preparing mapping libraries, it was useful to have both v1.1 and v2.0 data do work with. The data was thus manually cleaned and mapped to version 2.0 of the PHES-ODM, and both the original data, the transformation and cleaning code, and the v2.0 data can be found in this folder.
